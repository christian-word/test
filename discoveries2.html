Как использовать

1. Выберите стих из списка, введите свой текст или **продиктуйте его**.

2. Настройте фон, шрифт, эффекты и цвета.

3. Установите формат для изображения или видео.

4. Для видео выберите анимацию и озвучку.

5. Нажмите "Скачать фото" или "Создать видео".

Советы

Диктовка: Нажмите "Начать", продиктуйте текст и нажмите "Стоп". Текст появится в поле "Свой текст" и на превью.

Фон: Загружайте свои фото для персонализации.

Анимация: Выберите тип и длительность для динамичного видео.

Озвучка: Добавьте голос ElevenLabs для реалистичного звучания.

Форматы: Квадрат для Instagram, сторис для вертикального просмотра.
